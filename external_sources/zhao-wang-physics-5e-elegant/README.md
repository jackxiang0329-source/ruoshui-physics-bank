## 构建与质量

- `main.tex` 是ElegantBook/XeLaTeX合订入口，复用本仓库`../irodov-zh-elegant/elegantbook.cls`。
- `cover.tex`提供原创封面。
- `check_math.py`校验275个题号、每条`problemtext / workings / crosscheck`块结构和选定数值不变量。
- GitHub Actions `.github/workflows/zhao-wang-physics-elegantbook.yml`运行检查并构建`main.pdf`及`cover.pdf`，成功后将PDF回写仓库。
- `progress.md`记录原题范围与下一轮断点；`quality-check.md`保存勘误、模型假设和题图二校任务。

**限制：**这些是基于扫描件的非官方学习研究题解；自动数值与编译验收不等于完整学术专家复核，部分题图和原文仍需人工二校。书籍版权归权利人，用户提供扫描件不意味着公开再版已获授权。本项目没有复制或上传原PDF扫描页到GitHub。

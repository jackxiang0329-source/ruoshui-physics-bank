## 精确性与使用边界

- **《学习指导》例13.6存在真实原文矛盾**：题面明确写“每厘米590条”，但印刷解数值使用了“每毫米590条”。本稿分别列出两种解释，不把不一致的答案伪装为统一数值。
- 量子题12.2.9专门规定$\Delta x\Delta p\ge h$，与标准严格界限$\hbar/2$不同；均有明确说明。
- 12.3.15自然线宽寿命取决于谱线宽度定义；12.3.16单光子定位采用波包不确定性估计；单缝次极大采用教材半波带近似时不同于严格极值根，均明确标注。

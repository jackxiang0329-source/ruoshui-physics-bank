## 本轮需保留的严格条件

- **自测2.2.1**：原图A在上方、B在下方支撑板C上；弹簧受压缩，抽走C瞬间 **A加速度0、B向下2g**。按原图修正了错误的拉伸假设。
- **自测1.4.1**：竖直弹簧由原长静止释放，合力为零处伸长$mg/k$，最低点伸长$2mg/k$，不能混淆。
- **自测2.1.7**：滑轮当前逆时针旋转，不代表角加速度逆时针。
- **自测3.1.4**：同时性的相对性涉及运动方向；与两事件分离位移垂直的横向相对速度可保持同时。
- **自测3.2.7**：静质量密度和旧教材“运动质量密度”是两种不同定义，已分别列值，不伪装成唯一答案。
- **自测3.3.4**：东西接收站固定在地面，飞行器上计算的是两接收事件的洛伦兹时间差，不能把地面接收站错当成随飞机移动。

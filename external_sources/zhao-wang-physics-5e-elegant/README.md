## 构建与审校机制

`main.tex`是 ElegantBook / XeLaTeX 合订入口，继续复用本仓库`../irodov-zh-elegant/elegantbook.cls`和原创封面。`check_math.py`检验431个编号、逐题结构、章节引用和定量抽样。`progress.md`记录覆盖及断点；`quality-check.md`登记源图与题设疑点。GitHub Actions `.github/workflows/zhao-wang-physics-elegantbook.yml`检查、编译并在成功后回写`main.pdf`、`cover.pdf`。

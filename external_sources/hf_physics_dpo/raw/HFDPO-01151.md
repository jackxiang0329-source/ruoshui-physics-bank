# HFDPO-01151

Given that the system must maintain 20V bus voltage and supply 15A to life-support systems while preserving safety cutoffs at 12A per array, determine the magnitude and direction of current through each array using Kirchhoff’s laws—then explain how the fault could have been detected via current imbalance analysis.

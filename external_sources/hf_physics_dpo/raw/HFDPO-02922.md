# HFDPO-02922

In a remote Arctic research station, a critical weather sensor array fails during a geomagnetic storm, disrupting data transmission. The system relies on a custom-built, solar-powered network of six identical 12V batteries arranged in a complex looped configuration with resistive heating elements as load paths. During diagnostics, engineers measure three currents: 2.4 A through the main solar feed (I₁), 1.1 A through a redundant backup loop (I₂), and 0.6 A through a parallel ground loop (I₃), but no multimeter is available at the main junction. Using only Kirchhoff’s laws, determine the unknown current through the primary sensor line (I₄), given that two junctions have been shorted by ice damming, altering standard current splits.

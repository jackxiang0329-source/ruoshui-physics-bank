# HFDPO-13521

In a quantum optics lab, researchers use a tunable nanoscale grating to split a beam of single photons into two paths, then recombine them to observe interference. When the grating spacing is set to 320 nm, a strong interference pattern emerges with fringe spacing of 1.8 μm on a detector 1.2 m away. However, when they attempt to measure which path each photon took using a near-field probe sensitive to momentum transfer, the interference vanishes. If the probe’s resolution requires a momentum uncertainty of at least 3.5 × 10⁻²⁴ kg·m/s, calculate the minimum position uncertainty of the probe that would destroy interference. Does this violate the uncertainty principle? Explain.

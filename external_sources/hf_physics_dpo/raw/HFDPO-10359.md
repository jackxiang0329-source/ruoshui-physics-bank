# HFDPO-10359

A lunar rover’s power system uses a 12 V solar array with internal resistance 0.8 Ω, but during a dust storm, only 45% of the sun’s irradiance reaches the panels. The rover’s navigation computer (modeled as a 3.2 Ω variable resistor) draws 1.8 A during operation. To maintain performance, the system must deliver ≥8.4 V across the computer. Using a 1.5 Ω shunt resistor in parallel with the computer, you can divert excess current—yet this reduces efficiency. Evaluate whether this shunt is necessary and optimal, or if the system can self-regulate via the array’s internal resistance alone.

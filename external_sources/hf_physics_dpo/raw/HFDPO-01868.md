# HFDPO-01868

A fusion reactor's magnetic confinement system uses a toroidal superconducting coil array to stabilize a plasma at 150 million K. Engineers notice unexpected magnetic field asymmetries causing plasma instabilities. Given a 1.2 m-radius toroidal coil with 12,000 turns carrying 45 kA, and assuming the plasma occupies a 0.8 m-radius path within the torus, determine the minimum current required in a secondary correction coil (radius 0.6 m, 300 turns, placed 0.2 m from the main coil's axis) to cancel a 0.4 T field gradient caused by a misaligned main coil. Use both Ampère’s law and Biot-Savart integration for verification.

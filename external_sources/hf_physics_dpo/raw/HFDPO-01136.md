# HFDPO-01136

A drone delivery system must drop a package onto a moving delivery truck traveling at 25 m/s. The drone is flying horizontally at 40 m/s and 80 meters above the road. The package has no propulsion and experiences only gravity (ignore air resistance). At what horizontal distance ahead of the truck’s current position should the drone release the package so it lands exactly on the truck?

# HFDPO-08720

The sensor must distinguish between the tiny capacitive changes from cardiac pulses (ΔC ≈ 0.5 pF) and noise from motion artifacts. The circuit uses a 100 pF reference capacitor in a differential setup, with a 5 V excitation signal.

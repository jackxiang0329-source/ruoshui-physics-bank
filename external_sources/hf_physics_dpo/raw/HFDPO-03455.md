# HFDPO-03455

In a quantum computing lab, researchers observe unexpected interference patterns when single electrons tunnel through a nanoscale double-slit array embedded in a graphene sheet. However, when a nearby quantum dot is charged to monitor which slit each electron passes through, the interference fringes vanish.

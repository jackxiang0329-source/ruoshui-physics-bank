# HFDPO-01551

In a prototype Mars rover’s power distribution system, three solar array branches feed into a central junction box with non-identical internal resistances (R₁ = 0.8 Ω, R₂ = 1.2 Ω, R₃ = 0.6 Ω). During a dust storm, only two arrays are functional: Array A (24 V, R₁) and Array B (21 V, R₂), while Array C (23 V, R₃) is partially shaded and must be isolated. However, engineers discover a leakage path from Array C’s output to ground (resistance 20 kΩ), creating a parallel path through R₃. Determine the actual current flowing through each solar array and the voltage at the junction box if the system was designed for balanced loads.

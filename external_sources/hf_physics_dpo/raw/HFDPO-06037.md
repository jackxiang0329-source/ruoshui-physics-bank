# HFDPO-06037

A drone-mounted environmental sensor array, weighing 12 kg and shaped like a skewed rectangular prism, is suspended beneath a carbon-fiber quadcopter frame. The sensor is attached via three non-coplanar cables anchored to a rigid triangular support structure on the drone. The system is in static equilibrium but must withstand a lateral wind gust exerting 80 N at the sensor’s center, oriented 30° from horizontal. Determine the tension in each cable and assess whether any cable exceeds its 150 N breaking limit, using only vector analysis and moment equilibrium.

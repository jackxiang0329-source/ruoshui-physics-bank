# HFDPO-15152

A biomedical engineer is designing a new endoscopic imaging system to detect early-stage cancerous tissue using polarization-sensitive optical coherence tomography (OCT). The system uses near-infrared light (λ = 800 nm) incident on a layered tissue model: a 50 μm thick epithelial layer (n = 1.40) above a stromal layer (n = 1.37). To enhance contrast, the system exploits interference between p- and s-polarized reflections at the interface. The engineer notices that signal degradation occurs when the incident angle exceeds 55°—why? Calculate the minimum angle at which total internal reflection begins at the epithelial-stromal boundary, and explain how this affects the sensitivity of the OCT system.

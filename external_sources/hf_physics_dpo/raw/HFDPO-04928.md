# HFDPO-04928

The device's efficiency drops significantly below 450 nm, but the current output still increases when exposed to ultraviolet light (350 nm), despite the quantum dots being designed for visible absorption. Explain the discrepancy in behavior using wave-particle duality, and determine the probability that a 350 nm photon ejects an electron via the photoelectric effect in a 2 nm diameter quantum dot with a work function of 4.1 eV, considering both wave-like interference patterns and particle-like momentum conservation.

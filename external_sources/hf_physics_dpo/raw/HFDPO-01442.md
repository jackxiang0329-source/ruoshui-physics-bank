# HFDPO-01442

In a next-generation neural interface, researchers embed microscale capacitive sensors beneath the skull to detect subtle electrical fluctuations in brain tissue. Each sensor is a circular plate capacitor with a 50 μm radius, separated by a 100 nm dielectric layer of lipid bilayer (κ = 5). If the sensor must detect capacitance changes as small as 0.1 aF (10⁻¹⁸ F) to resolve neuronal activity, what is the minimum measurable change in ion concentration (in mol/L) that this system can detect, assuming uniform permittivity variation across the dielectric?

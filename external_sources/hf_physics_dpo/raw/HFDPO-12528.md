# HFDPO-12528

A deep-sea submersible uses a laser-based sonar system to map hydrothermal vents, but interference from refractive gradients in superheated fluid plumes causes beam distortion. The plume has a refractive index profile n(r) = 1.33 + 0.002e^(-r/5), where r is radial distance from the plume center in meters. A laser beam enters the plume at r = 2 m with an initial angle of 12° from the radial direction. Find the beam’s trajectory curvature and determine if it will escape the plume or be trapped in a stable oscillatory path.

# HFDPO-16264

A solar farm in a remote desert uses a grid of 12 identical photovoltaic panels, each with a variable voltage output (18–36 V) depending on sunlight intensity. An engineer notices a voltage surge in one string during the storm. Using Kirchhoff’s laws, determine the current through the diode protecting the affected string, assuming all panels have internal resistance of 0.5 Ω and the inverter draws 25 A total.

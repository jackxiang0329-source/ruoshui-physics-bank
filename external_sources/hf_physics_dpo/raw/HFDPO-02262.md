# HFDPO-02262

During peak winds, harmonic distortion from inverters causes the system to operate at 60 Hz, but the cable’s distributed parameters create a resonance that overheats the transformers. What is the resonant frequency of the cable system, and how should the grid operator adjust the system to avoid this?

# HFDPO-02027

A solar-powered irrigation system in a drought-prone region uses a network of three parallel 12V solar arrays connected to a central battery bank through a complex junction box with internal resistances. One array has a 0.5Ω internal resistance, the second a 0.3Ω resistance, and the third a 0.4Ω resistance. During peak sunlight, the first array generates 8A, the second 10A, and the third 9A. The battery bank draws 23A. Using Kirchhoff’s Laws, determine the current through the main output wire from the junction box to the battery.

# HFDPO-14507

A deep-sea hydrothermal vent system hosts a naturally occurring nuclear reactor anomaly—uranium-rich mineral deposits in a porous basalt matrix, submerged in seawater with trace dissolved neutrons from cosmic rays. Assume the system is approximately spherical and use diffusion theory with a neutron diffusion length of 3.2 m.

# HFDPO-15621

A biomedical engineer is designing a wearable device to monitor cardiac electrical activity using surface ECG electrodes. The signal amplifier must reject 60 Hz mains interference while preserving the 0.5–100 Hz ECG signal. To achieve this, a series RLC bandpass filter is added before amplification. Given a 10 kΩ resistor and a 100 μH inductor, what capacitance value (in nF) must be selected to center the filter at 60 Hz? Now, evaluate whether this filter effectively blocks 60 Hz noise despite the electrode’s parasitic impedance affecting the effective input impedance.

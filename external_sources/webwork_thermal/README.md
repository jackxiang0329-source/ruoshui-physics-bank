# WeBWorK 热学原始题源

来自 BrockPhysics/College_Physics_Urone 的第13—15章，覆盖气体动理论、热量传递、热力学第一和第二定律。此目录仅保存原始 `.pg` 源代码，连同来源Git版本、作者、许可信息和原始文件散列。默认开放题库条款需核对来源例外；尚无针对WeBWorK引擎或答案的成功运行记录，**全部未获准正式组卷**。


## 无损归档与恢复

21 份未审核的 `.pg` 原文已进入 [`../_bundles/webwork_thermal-raw.tar.gz`](../_bundles/webwork_thermal-raw.tar.gz)。来源版本、作者、原始程序均保持不变。运行时需要先在工作区执行 `python3 scripts/compact_webwork_sources.py --restore webwork_thermal`，不能把归档视为 LaTeX 转换或人工答案审核。

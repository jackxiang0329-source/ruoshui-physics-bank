## 第8和第17章本轮重要核验

1. **8.6参考系订正**：第（1）问是地球反射信号那一刻
   `飞船系`的距离，正确约**9.0×10⁹m**，
   而不是发送瞬间`地球系`距离3.0×10⁹m；
   第（2）问地球系收信距离约2.7×10¹⁰m。
   与辅导书S PDF127页核对后，已修改题面、解析和检查。
2. **8.20「资用能」**：该教材指`质心系总能量`，
   采用精确质子质量约**6.493GeV**；
   辅导书S PDF134页将质子静能取整至1GeV，
   得约**6.7GeV**。两数源于精度约定，不是不同物理定义。
3. **8.23极高能量模型**：两个质子均提高能量时，
   按源教材粗略牛顿引力模型有 (F_g\propto E^2)；
   质子各自需达到约10¹⁸GeV，非只提高一个质子。
4. **17.3指南针偏角**：正交磁场角约15.5°，
   若优化水平导线场方向则最大约16.1°，
   与辅导书S PDF254页一致。
5. **17.6半圆载流导线**：若求完整磁场矢量，
   不能只给整圆环轴向场的一半；还有横向分量，
   源图方向由参数化坐标决定。
6. **17.12托卡马克**：铜线单匝周长取环管截面
   **小半径1m**，不是主环大半径2m；
   约1592匝、(B\approx11.6\,\mathrm T)，
   与S PDF259页核实。
7. **17.11半无限螺线管**与**17.1、17.5、17.6等图依赖题**
   仍须第三方图示/边界条件独立校验；自动抽检不予正式准入。

历史仍未关闭的关键源分歧包括3.14火箭高度、
5.6 C₆₀ 印刷尺度、6.21能级编号、
7.12相干干涉相位判据与16.11电路支路电流等，

## 最新批次：第30章《核物理》（22道章末习题＋22份独立解析）

**两个非常重要的源书物理模型差异：**
1. **30.17 钴块中子活化：**辅导书S PDF397的薄靶公式算活度约0.42Ci，却对应每秒俘获 (1.74\times10^{14}) 颗中子，超过单向入射到2cm见方截面时每秒 (8.0\times10^{12}) 颗的总入射数。题给光学厚度 (Sigma d\simeq21.7\gg1)，薄靶公式不自洽。在单向、纯吸收、自屏蔽近似下得到约 **0.0194Ci**，真实角分布和散射需要更多信息，不能将此当作唯一实测值。

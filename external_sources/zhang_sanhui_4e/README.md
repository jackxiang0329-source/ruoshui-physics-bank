### 本批重要物理审查

- **9.3**：自行车内胎视为环形管、每次打气筒输送环境状态气体，结果约3.94倍环境`绝对压强`；有效内胎体积与死腔损失为待核实模型条件。
- **9.24**：佩兰布朗运动原始统计7160、3360、1620、860，阿伏伽德罗常数估算会因取用不同层数区间而变化。保留观测差异，不硬替换成现代常数。
- **9.25**：存在液态水时的`饱和`水蒸气，等温压缩体积一半时压强仍约1atm，不是2atm。
- **9.27**：配套S PDF第153页明确给出图9.18临界点`Vm,c=9.55×10⁻⁵m³/mol`、`pc=7.23×10⁶Pa`；据此`a≈0.198 Pa·m⁶/mol²`、`b≈3.18×10⁻⁵m³/mol`；已替换先前未核图的估算，原图矢量重绘仍待办。
- **18.12**：霍尔数密度约`2.86×10²⁰m⁻³`，半导体P/N型必须再次明确原图18.24的电势极性和A/A'位置。
- **18.17、18.22、18.24、18.26、18.27**：受力方向、部分浸入场的线圈、磁压与轨道炮的源图几何仍有审核标记。

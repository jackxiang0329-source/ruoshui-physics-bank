## 沿用大学物理中文译稿的合订原则

- 不创建一道题一个 Markdown 文件。每章统一保存一份权威的 questions.tex 和一份 solutions.tex，原题号顺序编排。
- 所有公式采用 LaTeX 数学环境，公式源是可以供统一文档 input 的片段，不带 documentclass。
- source_register.json 记录唯一稳定题号、对应教材与辅导书页码、风险与审核状态；不要复制成第二份可编辑主索引。
- 遵循原书题设，不擅自改变数值、单位和符号；图示依赖必须明示。所有解析独立推导并对照辅导书核查，不直接照抄。
- 与正式高难 bank/ 和原 OpenStax 翻译保持隔离；未完成独立审阅、跨库去重与许可核验时，exam_ready=false，不进入正式组卷统计。

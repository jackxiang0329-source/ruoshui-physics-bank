# PREF-00049 · challenge

A spacecraft navigation error report is worded exactly like a real historical case: one team reported thruster impulse in pound-force-seconds, and another team's software expected newton-seconds. Given that $1$ pound-force-second $\approx 4.448$ N·s, and a required impulse of $500$ N·s was instead supplied as $500$ lbf·s without conversion, calculate the percentage error this mistake would introduce.

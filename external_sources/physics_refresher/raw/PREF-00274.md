# PREF-00274 · challenge

A conical pendulum (a mass on a string moving in a horizontal circle while the string traces a cone shape, making a constant angle $\phi$ with the vertical) provides its centripetal force through the horizontal component of the string tension, with the vertical component balancing gravity. Given a string length of 2.5 m and an angle $\phi=20°$ from vertical, find the mass's speed and the period of its circular motion.

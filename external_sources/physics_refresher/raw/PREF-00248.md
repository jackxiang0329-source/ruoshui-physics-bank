# PREF-00248 · challenge

A 1200 kg car traveling at 30 m/s brakes to a stop. Using the work-energy theorem, find the work done by the braking force. If the same car had been traveling at 60 m/s instead, find the new work required to stop it, and explain numerically why this is not simply double the first value.

# PREF-00625 · challenge

Using the general reasoning from this lesson (stronger restoring force → faster wave; more inertia → slower wave), predict, qualitatively, how the speed of sound in a solid, a liquid, and a gas should compare to each other, given that solids are generally much stiffer (able to exert stronger restoring forces upon compression) than liquids, which are in turn stiffer than gases; state your predicted ordering and briefly justify it using the string-wave-speed intuition from this lesson (you do not need the exact formula for sound speed in each medium, only the qualitative reasoning pattern).

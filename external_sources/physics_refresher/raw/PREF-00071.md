# PREF-00071 · challenge

A student measures the same object's length ten times and gets values scattered between $9.8$ cm and $10.4$ cm, with no obvious pattern. A second student, using a different ruler, consistently gets values around $10.0$ cm with almost no scatter, but a laser reference measurement shows the true length is $10.5$ cm. Compare the accuracy and precision of both students' measurements, and identify which type of error (systematic or random) explains each student's result.

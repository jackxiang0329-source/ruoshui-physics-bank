# PREF-00549 · challenge

A pendulum clock is designed for a period of exactly 2.0 s at $g=9.8$ m/s². If the clock is transported to a location where $g=9.79$ m/s² (a very slightly weaker gravity, as can occur at different altitudes/latitudes), find the new period, and determine whether the clock will now run slightly fast or slightly slow (hint: a longer period means each "tick" takes more real time, i.e., the clock runs slow).

# PREF-00198 · challenge

Determine whether the block remains stationary without any applied force, by comparing the driving force component ($mg\sin\theta$) to the maximum static friction ($\mu_s mg\cos\theta$), and if it does not remain stationary, find its acceleration using $\mu_k = 0.4$.

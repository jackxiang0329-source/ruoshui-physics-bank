# PREF-00672 · challenge

A guitar has six strings, each tuned to a different fundamental frequency, but designed with similar tension (within a comfortable playing range) by varying linear mass density between strings instead. If the lowest string (E2, ~82 Hz) and highest string (E4, ~330 Hz) have the same length (0.65 m) and are under roughly the same tension, find the ratio of their linear mass densities required to produce this frequency ratio (hint: use $f_1=\sqrt{T/\mu}/(2L)$ and solve for the $\mu$ ratio with $T$ and $L$ held constant).

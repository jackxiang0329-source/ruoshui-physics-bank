# PREF-00099 · challenge

A surveyor records displacement vectors between four property corners: A to B is $(50, 0)$ m, B to C is $(0, 30)$ m, C to D is $(-50, 0)$ m, and D back to A is $(0, -30)$ m. Verify, using vector addition, that this forms a closed shape (i.e., that the four displacement vectors sum to zero), and explain what it would mean physically if they did not.

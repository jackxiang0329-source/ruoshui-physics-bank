- main.tex 使用同库 Irodov ElegantBook 类；从本目录执行 XeLaTeX，需先使 elegantbook.cls 可用。尚未实际编译，不宣称 PDF 已生成。
- 各批依据原页图像逐题读题、独立推导、手工回代或极限/量纲检查。待独立二校，不声称第三方终审。

- 不得把占位文件、未辨识题、公式乱码、或未审图题计入录入数量。

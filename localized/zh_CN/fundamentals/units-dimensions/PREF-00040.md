# PREF-00040｜物理量、单位与量纲

**学科：** 物理基础　**知识点：** 物理量、单位与量纲　**题型：** 计算与估算题

**审核状态：** 术语初校；待独立双语审核、物理答案审核及版权审核；不可正式组卷。

## 中文译题

已知电流公式 $I=q/t$，其中 $q$ 为电荷量（单位为库仑 C）、$t$ 为时间，求电流的国际单位制基本单位，并利用 $1\text{ C}=1\text{ A}\cdot\text{s}$ 验证其与安培的一致性。

## 英文原题（原文对照）

Given the equation for electric current, $I = q/t$, where $q$ is charge (measured in coulombs, C) and $t$ is time, find the SI base unit of current and confirm it matches the ampere by using the relation $1\text{ C} = 1\text{ A}\cdot\text{s}$.

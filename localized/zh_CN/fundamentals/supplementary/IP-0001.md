# IP-0001｜用国际单位制词头表示质量

## 中文译题

将质量 $1.93\times10^{13}\,\mathrm{kg}$ 改写为带有适当国际单位制词头的形式，使数值大于 $1$ 且小于 $1000$。

# Metric Prefixes

Restate the mass $1.93 \times 10^{13}\ {\rm kg}$ using a metric prefix such that the resulting numerical value is bigger than one but less than 1000.

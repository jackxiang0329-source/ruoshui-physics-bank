# 数学公式 LaTeX 排版准入规范（第36批起）

适用范围：大学物理题库全部试题、解析、合订PDF。

## 源数据与生成器

- 数学必须位于真实TeX数学环境中：短式使用 \( ... \)，复杂推导使用 \[ ... \]，可使用 equation、aligned 等结构。
- 不允许把希腊字母、上下标、积分、根式、微分号、不等号等Unicode数学符号直接当作正文公式；应使用 \omega、x^2、\int、\sqrt{}、\partial、\le 等真正LaTeX命令。
- 禁止将数学反斜线转义为普通正文后直接打印；渲染器必须分离正文与数学区段，仅转义正文。
- 长公式应改用行间公式，并控制宽度、括号和对齐，避免密集的一整行纯文本。
- A4、ctexbook、XeLaTeX；中文优先 Noto Serif CJK SC，西文优先 TeX Gyre Pagella，数学优先 TeX Gyre Pagella Math，必要时降级到 Latin Modern Math。
- 双册PDF执行两遍XeLaTeX、50个题号核验、日志零缺字和零编译错误；题目源文件与合订册保持一致。
- 禁止人工编辑编译后PDF来掩盖题源错误。

## 独立学术审核

- 每轮50道高难综合题，每题四个递进分问、四份解析和多知识点联动；禁止单步基础题及纯难度标签升级。
- 每个分问需实际执行物理或数学复算，优先使用独立数值积分、有限差分、不同模型推导、守恒量、边界条件、临界性和极限分析，禁止恒真断言充数。
- 自动计算与排版技术检查不能冒充专家逐式审核。未完成独立学术复核与全库历史物理模型去重时，只能存于审核分支并标记待独立复核，不合并正式主库。
- 所有交付文件由GitHub Actions直接生成并推送GitHub，无本地交付。

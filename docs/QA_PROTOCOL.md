## 尚待六轮人工/独立审核

1. **题意审查**：条件是否充分、物理模型是否可实现，参数与情境是否明确。
2. **推导审查**：独立解题及量纲、极限、数量级、数值实验的核验。
3. **答案审查**：答案与题设、单位、求解对象、隐含条件逐一对应。
4. **原创审查**：针对**有访问许可**的教材和公开题库，进行实质性语义相似度与图表比较。
5. **命题审查**：难度、知识覆盖、题型结构、区分度、歧义与中文规范。
6. **出版审查**：逐页校对、图示与字体、公式断行、PDF 字体嵌入和权限。

## 审核门禁

每题 JSON `quality_status` 当前均为 `待独立复核`。机器公式核对通过不能自动改写此字段。实际执行每轮人工审核时，应记录审核人、日期、问题、证据、版本 SHA、复审结果；只有全部满足才标 `质检通过`。

## 注意

本项目只核对公开的部分出版社书目页；**尚未**逐本阅读全文。不能宣称全部试题与所有教材不重合。编译通过和机器比对通过不等于物理结论全面可靠。

新增 `scripts/check_review.py`：题目仍为待独立复核时不予正式选用；若人为改成「质检通过」而没有 `qa/ID.json` 六轮批准凭证，CI 将拒绝。凭证以原题 `question.tex` 和 `solution.tex` 的 SHA-256 绑定，避免审核后偷换内容。门禁仅核对证据形式，不能替代人工独立复核。见 `qa/README.md`。

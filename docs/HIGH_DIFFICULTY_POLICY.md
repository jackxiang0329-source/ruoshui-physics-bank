# 高难度综合题准入规则

1. 只准 `tier=advanced_composite`，`level=4/5`，预计解题 >=40 分钟。
2. 每题至少四个相互递进小问与三个相互关联知识标签；应要求建模、推导、参数/临界条件、极限或能量一致性分析。
3. 不收录单步代入、基础选择/填空、纯数值替换、普通教材套题和通过修改难度标签伪装的简单题。
4. 每题必须给出条件、独立可复核解答与物理约束；自动检查和编译成功不得冒充六轮专家复核。
5. 旧版100道原创样板不符合上述当前综合题门槛，已清出活跃主库；同编号新12题是不同内容。保留 Git 历史便于审计。
6. 外部上游原始语料尚未完成逐题审核，为避免误删潜在高难题，仅作隔离候选。不进入正式题库、组卷、PDF，定时导入禁用；未来仅通过独立专家判断后才准许人工迁入。


## 第十一批起：每轮恰好新增100道、严格质检

1. **数量与覆盖**：每轮新增100道不同的高难度综合题及完整解析；六大模块各16或17道，任何尚未通过全轮门禁的内容只能作为工作分支草稿，不计入正式主库新增数。
2. **四问与独立解答**：题面、解答分别包含对应的(1)–(4)四个递进部分，物理边界、正负号与量纲自洽，逐问提供数学或物理推导，而不是简单写结果。
3. **严格技术质检**：每题四个实际执行的分问校验，共至少400项，每题至少涵盖两种验证方法（符号恒等式、独立数值、极限、量纲、守恒量、独立推导、物理特例）。自动报告记录题号、分问、方法和结果。禁止用恒真断言充数。
4. **排版与去重**：所有题目沿用唯一源目录 bank/ID，镜像、索引和两册合订TeX同步；全库重复度、难度门禁、TeX结构和题册及解答册XeLaTeX实测必须通过，不能以手工修改PDF替代源码。
5. **审校证据分级**：自动测试、编译通过不代表已有独立学术审稿人逐题复核。未经真实人工复核，仍必须写明「待独立复核」，不可自行标记「六轮专家质检通过」。需要人工核对每个测试是否真正覆盖其对应的结论。
6. **主分支合并规则**：只有整轮100题、400分问技术校验、分支CI与双PDF全部通过，才允许合并；若不满足，保持在工作分支修正。未来批次的机器门禁为 scripts/check_future_rounds.py，配额与基线在 data/rounds/quality_policy.json。

# 五星综合题的内部进阶梯度

在不降低原有4/5、5/5最低标准的前提下，对五星综合题进一步设内部排序：

- **L5-A**：高阶综合，4个递进问题，2–3类守恒/边界推导和完整模型，偏重准确计算。
- **L5-B**：强化综合，包含近似、积分、复变量、频域方法或多模型联立，强调参数适用域。
- **L5-C**：高数学负荷，涉及变分法、变系数本征谱、复杂散射或动力学极限，强调完整分析。
- L4-A/B/C 预留给适合4/5的综合压轴题；全部仍大幅高于普通习题。

这是编辑内部的相对难度量表，不表示题目已经经过外部专家客观校准，也不表示科研成果。某题评级可在真实学生试做与独立审阅后修订。

第四批24题按 A/B/C 8/8/8 分布，单个批次的数据与题号写在一个集中 JSON 清单；旧版30道不做未经审核的强制追评级。后续以每批200道为产能目标，但实际接收入库数只按合格作品统计。

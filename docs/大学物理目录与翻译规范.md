# 大学物理目录与翻译规范

外部候选习题采用**不移动原件的分类视图**：原始英文题源固定保存在 external_sources/*/raw 中（上游版本和 Git SHA 不变），完整中文目录保存在 external_sources/catalog/题目总索引.csv，按学科生成 external_sources/catalog/按学科/*.csv。

## 权威来源与加工文件

| 目录 | 内容 |
| --- | --- |
| bank/ID/{question.tex,solution.tex,meta.json} | 100 道原创样板题的权威来源，原有编号稳定 |
| external_sources/*/raw | 英文题源镜像；不重命名、翻译覆盖或移动 |

| localized/zh_CN/模块代码/知识点代码/ID.md | 中英对照题目，非正式题库 |

## 分类质量

物理基础、力学、电磁学、热学、振动与波动、光学、近代物理七大模块；无法可靠归属学科的题保留“待分类”。只有固定上游章节与知识点对应的题才细分，其他只保留可信的一层学科，二级分类写“未细分（待核验）”。

PREF-00011、PREF-00019 上游虽标为计算题，但原文只要求解释与判断，因此保留原始上游标签并在中文索引改为概念辨析题。今后错分必须逐题留痕，不能通过通用关键词替换所有题型。

## 翻译原则

1. 原始数值、公式、单位、假设、条件、图示引用和原题顺序必须完整保留。
2. 统一区分位移与路程、速度与速率、电势与电势能、功与功率、误差与不确定度。
3. 翻译初校与物理学术复核是不同阶段，不可混为“已审定”。
4. 生成脚本拒绝不匹配源哈希及不符合关键术语的译稿；遇到缺失图像或上下文时标记风险，不补写条件。
5. 外部题源即使翻译完成，也永远保留版权、答案、语义去重三项待审核门禁。

## OpenStax 与 PHYS 2425 补充译稿

沿用唯一中文译文档案 localization/zh_CN/translations.json：原先的 entries 保留 Physics Refresher 译文，additional_entries 集中维护 12 道 OpenStax / PHYS 2425 初译，含稳定 ID、原始 Git blob SHA、知识点和风险提示。运行 python scripts/export_zh_review.py --check 可核验来源及状态，运行 python scripts/export_zh_review.py 将按主类输出一份合订初译和 CSV 索引到 generated/zh_review。与 88 道 Refresher 译稿同属待双语复核的编辑候选，不应认定100道已审核。

经源题内容确认：CP-00898 属热学—热辐射，不是核物理；CP-00080 属力学—牛顿运动定律，不能按章节标题“Problem-Solving Strategies”归类。其余含歧义章节标题继续保留待核验。

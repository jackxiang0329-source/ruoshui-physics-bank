# 高难综合物理批次制与 200 题目标

- 正式题库使用 `bank/ID/meta.json`、`question.tex`、`solution.tex`，严格按六大模块自动排序；不在根目录生成单题文件。
- 一轮最多提交 200 个**不同的已完整推导**题目。编辑收集时先放在单个 JSON 批次文件（由用户自行提交该 JSON 即可），用 `python scripts/bulk_import.py --batch <path>` 先干运行，核对 4 个子问、难度、知识标签、完整解答、题号及 7 字符片段重复。
- 人工复核来源、解题细节和语义相似度后，运行 `python scripts/bulk_import.py --batch <path> --apply`；脚本会写入规范题目目录、同步唯一 JSON 镜像，再生成 TeX、索引与 QA 报告。后续通过 Git 提交整个批次。
- `python scripts/quality_gate_bulk.py` 是提交后全库自动检查，在仓库 CI 中执行。它使用字符 7-gram 降低“换数字”造成的原文重复风险，但**不具备对语义相似和物理公式正确性的完全识别能力**；不可作为人工独立审稿证据。
- 新增题必须具备模型假设、4 个递进小问、完整推导、3+ 跨知识点标签、40 分钟以上真实难度、清楚的参数区间以及极限/能量/量纲校核。低于标准的题保留在编辑侧，不导入正式题库。
- 所有题仍以 `待独立复核` 入库。机器公式检查、PDF 排版通过不意味着六轮专家审定。
- 以 200 道为**单轮计划容量**，不是当前已完成录入数；不得以数字、参数平移或机械重排凑题数。下一轮可分子批验证，全部稳定后再合并主支。
